## What was imported

Everything needed to build a Pando interface without network access:

- `styles.css` and all eight files in `tokens/`
- All 24 React components in `components/`
- `index.js`, written here — the adherence config expects consumers to import
  from a barrel, and the design project does not ship one
- `readme.md` — the brand spec in full
- `_adherence.oxlintrc.json` — the lint rules
- `SKILL.md` — rewritten as a Claude Code skill (the original was written for a
  different skill host and pointed at `README.md`, which does not exist there)

## What was left in the design project

These render as specimen cards in the Design System pane and are reference
rather than build inputs. The prose rules they illustrate are all in
`readme.md`:

- `guidelines/*.html` — 21 specimen cards for color, type, spacing and brand
- `components/**/*.card.html` — seven component specimen pages
- `ui_kits/console/` and `ui_kits/site/` — clickable prototypes of the console
  and the marketing site, built from the spec's wireframes
- `components/**/*.d.ts` and `components/**/*.prompt.md` — per-component types
  and usage rules
- `_ds_bundle.js`, `_ds_manifest.json`, `thumbnail.html` — preview infrastructure,
  regenerated by the design app

**Pull any of them when needed.** The console work in phase 8 will want the
`.d.ts` files (the console is TypeScript) and the `.prompt.md` files (each states
when *not* to use a component), and `ui_kits/console/` is a working prototype of
the very screens that phase builds — worth reading before designing them again.

## Re-syncing

`DesignSync` reads and writes the project; `/design-login` authorizes it. To read
a file:

```
DesignSync(method: "get_file",
           projectId: "27583278-89f3-4207-b9af-3fa14d54764a",
           path: "components/core/Button.prompt.md")
```

`list_files` enumerates everything. The `/design-sync` skill is the supported way
to keep a local library in step with the project — incrementally, one component
at a time, never as a wholesale replace.

## Known substitutions, from the source readme

Two things the brand spec describes but did not ship, both flagged upstream:

- **Icons** are Lucide, loaded from the unpkg CDN rather than vendored. For
  production or offline use, vendor the icons actually used and point `Icon` at
  them.
- **Fonts** are loaded from Google Fonts. Self-hosting means supplying licensed
  `.woff2` files and turning `tokens/fonts.css` into local `@font-face` rules.
- **The logo** in `components/brand/Logo.jsx` is built from the spec's written
  description, not from official artwork. If real logo files exist, they replace it.
